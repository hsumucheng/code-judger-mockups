# CHANGELOG — AI 導師額度管理 UI 模擬變更紀錄

依據會議紀錄（page7 / page11 / page14）與後續回饋整理的完整變更清單，方便工程師快速掌握每個頁面改了什麼、為什麼改。

## `quota-page-mockup.html`（單位管理主控臺 → 課程 AI 額度管理，page11 / page14-3-2）

**頂部統計卡片**
- 原本純文字列「總額度: xxx | 已分配額度: xxx | 未分配額度: xxx」，改為卡片式呈現
- 擴充為五個數值：總額度、已分配額度、未分配額度、已使用額度、未使用額度
- 卡片呈現方式：總額度獨立一框（較窄）；已分配額度＋未分配額度合併一框（中間分隔線）；已使用額度＋未使用額度合併一框
- 每個數值下方皆有實體進度條
- 顏色配置：總額度＝深藍灰、已分配＝青色、未分配＝橘色、已使用＝綠色、未使用＝灰藍色
- 單位改為 **kToken**（例：56,201 → 56k），卡片上單位標示為「Token」（k 已內含於數字）

**下方課程列表表格**
- 「分配額度」欄位右側新增「已分配」欄位
- 完整欄位順序：課程名稱、課程結束日、教師、AI 導師、分配額度(Token)、已分配(Token)、已使用(Token)、未使用(Token)、操作
- 表格內數字維持**完整數字**（不use k 縮寫），只有頂部卡片使用 k 格式
- 操作欄統一每一列都顯示「分配、回收、異動歷程」三顆按鈕（原本額度為 0 的課程只顯示「異動歷程」一顆，造成按鈕位置不對齊，已修正為一致呈現）

**版面修正**
- 表格標題文字＋排序箭頭（↑↓）不再換行，箭頭固定在文字右側
- 三張卡片的進度條起始位置已對齊（原本總額度卡片的進度條比其他卡片低一截）
- 表格外層加上可水平捲動容器，避免欄位變多後版面跑版

## `disable-ai-tutor-modal.html`（停用單位 AI 導師 — 防呆視窗，互動原型）

- 完整三階段流程：
  1. 選擇「不回收」或「一併回收」旗下課程剩餘額度（圓形單選按鈕，預設「不回收」）
  2. 選擇「一併回收」後自動跳轉二次確認畫面，需勾選「我了解…」才能啟用確認按鈕
  3. 確認後顯示對應的結果畫面（不回收 / 一併回收兩種文案）
- 防呆邏輯：
  - 第一階段的「不回收」與「一併回收」互斥（單選行為）
  - 第二階段「一併回收」為延續上一步的已選狀態，設為 `disabled` 且 `pointer-events: none`，無法被再次點擊取消
  - 退回第一階段的唯一途徑是按「取消」按鈕（第二階段按「取消」會退回第一階段，非直接關閉視窗；第一階段按「取消」才會關閉整個視窗）
  - 「我了解…」未勾選前，確認按鈕維持 disabled 灰階狀態
